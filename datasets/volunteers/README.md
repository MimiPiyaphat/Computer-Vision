# วิดีโออาสาสมัครสำหรับเดโมวิชา Computer Vision

ข้อมูลวันที่ 7 ตุลาคม 2026: 17 คลิป / 5 คน ความยาวประมาณ 5–12 วินาที
หน้านิ่ง 5, ยิ้ม 6, กระพริบตา 5, ยกแขน 1

## เปิดเดโม

1. รัน `python desktop.py` ตามปกติ
2. กด **Dev** และใส่รหัสผ่านที่ตั้งไว้
3. เปิดแท็บ **อาสาสมัคร · จำแนกท่าทาง** เพื่อดู confusion matrix
4. กด **เปิดวิดีโอเดโมจากไฟล์** แล้วเลือกคลิป เล่น/พัก หรือเริ่มคลิปใหม่
5. แท็บ **อาสาสมัคร · คุณภาพ / ข้อจำกัด** แสดงจำนวนเฟรมที่วัดได้และผลแยกคน

เดโมเล่นวิดีโอต้นฉบับแบบออฟไลน์ ไม่มีเสียง ไม่เปิดกล้อง ไม่สร้าง visit/baseline
และไม่แสดงผลเป็นการตรวจโรค หน้าต่างวิดีโอจะปิดเมื่อออกจากหน้า Dev หรือครบเวลาล็อก
รหัสผ่านป้องกันเฉพาะการเข้าหน้า UI ไม่ใช่การเข้ารหัสไฟล์ในเครื่อง

## การทดลองที่ทำ

- เก็บต้นฉบับ ZIP ไว้ ไม่ตัด/แต่ง/สร้างวิดีโอเพื่ออ้างว่าเป็นข้อมูลผู้ป่วย
- เปลี่ยนชื่อสำเนาเป็น p01–p05, ตรวจ SHA256 และไม่อนุญาตคลิปซ้ำ
- ชื่อไฟล์ใช้เป็น label **ท่าทาง**; ไม่อนุมานว่าปกติ/เป็น stroke จากใบหน้า
- ตรวจภาพตัวอย่าง 3 ตำแหน่งต่อคลิป ไม่ถือเป็นการตรวจ label ทางการแพทย์
- ใช้ FaceAnalyzer/MediaPipe เดิม: ต้องเห็นใบหน้าเดียว มุมศีรษะและแสงผ่านเกณฑ์
- ถอดรหัสทั้งคลิป สุ่มวัดประมาณ 15 fps, ย่อภาพให้ด้านยาวไม่เกิน 960 pixels
- ใช้ mouth width/open/lift และลักษณะ EAR ตามเวลา เป็น features 6 ตัว
- ใช้ standardized nearest-centroid เป็นโมเดลทดลองขนาดเล็ก ไม่มี hyperparameter search
- **Leave-one-person-out 5 รอบ**: แต่ละรอบฝึก 4 คน ทดสอบคนที่เหลือ
  คำนวณ scaler และ centroid จากชุดฝึกในรอบนั้นเท่านั้น ไม่สุ่มแยกเฟรม
- รวมคะแนนทำนายที่กันคนทดสอบไว้ของ 16 คลิปใบหน้า; แขน 1 คลิปใช้เล่นเดโมเท่านั้น
- โมเดลท้ายสุดที่ fit ทุกคลิปส่งออกแยกไว้ ไม่ใช้วัด accuracy กับข้อมูลฝึกตัวเอง
  และไม่ถูกโหลดเข้า pipeline เตือน stroke

ข้อมูลและรายงานทั้งหมดอยู่ใต้ `data/volunteers-20261007/` ซึ่ง Git ignore ไว้:

```text
archives/p01.zip … p05.zip       สำเนา ZIP ต้นฉบับ
prepared/manifest.jsonl          label, hash, FPS, ระยะเวลา, รหัสคน
prepared/videos/                วิดีโอสำเนา
prepared/*-contact.jpg          ภาพตัวอย่าง
prepared/private-source-map.json ที่มาของไฟล์ (มีชื่อจริง ไม่เผยแพร่)
evaluation-v2/report.json        รายงานที่หน้า Dev ใช้
evaluation-v2/gesture-model.json โมเดลจำแนกท่าทางทดลอง
evaluation-v2/*.timeline.json    features ตามเวลา
```

`evaluation-v1` เป็นรอบตรวจ pipeline ก่อนแก้จังหวะ sampling ให้สม่ำเสมอข้าม FPS
และคำนวณอัตราเปลี่ยน EAR ต่อวินาที เก็บไว้เพื่อตรวจย้อนหลัง ไม่ใช้เลือกโมเดลที่คะแนนสูงกว่า
คำสั่งสร้างผลซ้ำ (ต้องใช้ output ใหม่เพื่อไม่ทับงานเดิม):

```powershell
python -m datasets.volunteers.prepare --output data/volunteers-20261007/prepared-copy
python -m datasets.volunteers.evaluate --output data/volunteers-20261007/evaluation-repeat
python -m unittest discover -s tests -p "test_volunteer_dataset.py"
```

## ขอบเขตสำหรับนำเสนออาจารย์

กล่าวได้ว่าเป็น **ต้นแบบเก็บข้อมูล / สกัดจุดใบหน้า / จำแนกท่าทาง / เปรียบเทียบข้อมูล**
และรายงานคะแนนจริงบนอาสาสมัครที่กันคนออกจากชุดฝึก
กล่าวไม่ได้ว่าเป็น accuracy ของ stroke, ความไวต่อโรค, หรือเปอร์เซ็นต์ความเสี่ยงโรค
ไม่มีคู่ก่อน–หลังนวด ไม่มีผลวินิจฉัย ไม่มีท่าหลับตาค้าง และมีข้อมูลแขนเพียงคนเดียว
จำนวนคนยังน้อย ช่วงความเชื่อมั่นแบบรายคลิปไม่ครอบคลุมความสัมพันธ์ภายในคนเดียวกัน
คะแนนจำแนกท่าทางจึงเป็นผลทดลองเบื้องต้น ไม่ใช่หลักฐานรับรองความปลอดภัย

ไม่ต้องสร้างผู้ป่วยปลอมหรือเพิ่มจำนวนด้วยคลิปซ้ำเพื่อทำให้คะแนนสูง
หากมีเวลาเก็บเพิ่ม ควรถ่ายขั้นตอนครบสองรอบในคนเดิมด้วยตำแหน่งกล้องเดิม
เพื่อวัด **ความสม่ำเสมอของการวัดซ้ำ** ไม่ติด label ว่าเป็น stroke
ขอความยินยอมก่อนนำใบหน้าไปแสดงในชั้นเรียน และไม่เผยแพร่ ZIP/ภาพ/วิดีโอหรือ features รายบุคคลสู่ GitHub
